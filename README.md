# Comixdownloader 
This is a code to convert a chapter of a manga or manhwa from comix to cbz. 

It uses extract.pics api to grab images then serves them to your current folder for zipping and that's how you get your cbz file.

## Prerequisites
1. Python
2. extracts.pics account
3. Internet

## Instructions
1. Download comixdownloader.py to your computer
2. [OPTIONAL] Put in a separate folder e.g. Downloads/Comix to separate it from your normal downloads
3. Open extracts.pic and go to api and create new project then copy the api
4. Copy the api key
5. Open comixdownloader.py in notepad/any text editor, then paste the api into "YOUR_API_KEY_HERE"
6. Save and then close
7. Open the .py file and paste your comix link then press enter. Wait for download
